# Короткая проба Nemotron: F32 / F16 / Q8

Продолжение этой серии: [завершённая проба F32/Q8 на синтетическом и естественном36с входе](nemotron-followup-ci-2026-11-07.md). Ниже сохранён первоначальный результат с таймаутом F16.

[CI run42378985219](https://github.com/Droidje/vexto/actions/runs/42378985219), исходники08e7cfc, native backend из успешной сборки9099193. Текущий frontend пересобран NDK28.2.13676358. [Полученные результаты JSON](results/nemotron-precision-ci-2026-11-07.json) включают SHA исходных файлов и resampled PCM.

Отдельный Pixel7 AVD Android35 x86_64, RAM4096MB (MemTotal4013940KiB), 4CPU. AVX2 гостю **недоступен**, поэтому ускоренный ISA-путь здесь не измерен. Все модели работали на CPU с4потоками. Аудио — пять публичных русских RINCO-файлов3.2–5.9с. Эталон — интервалы реплик, не покадровая разметка речи. DER: collar0, overlap scored, глобальное сопоставление спикеров. Объединённый DER считается по сумме error/reference speaker-seconds.

| Веса | DER пяти клипов | Медиана времени процесса с ADB | Сумма времени пяти запусков |
|---|---:|---:|---:|
| F32 | 11.954% | 4.857с | 32.295с |
| F16 | 11.954% | 9.057с | 44.245с |
| Q8_0 | 11.833% | 2.780с | 17.003с |

Запуски однократные, порядок F32→F16→Q8 фиксирован; кеши ОС и холодная загрузка не контролировались. Первый F32 занял16.321с. Это разведочная проба native-процесса, не доказательство коэффициента ускорения приложения, устойчивого преимущества precision или сохранения качества на сложных разговорах. WER, peak RSS приложения и полный RTF нового конвейера здесь не измерялись.

Дополнительно файл05 повторён6раз с паузами250мс: синтетический37.044с вход пересекает границу кеша30.4с. **F32:18.176с, опубликованный стабильный префикс точно совпал с финальным RTTM.** Само качество этого искусственного повтора плохое: DER52.396%, два эталонных голоса сведены к одному. Совпадение префикса подтверждает стабильность геометрии, а не качество диаризации. Синтетический повтор не заменяет естественный разговор.

F16 на повторе превысил ограничение45с. Поэтому CI завершился с ошибкой, Q8 на повторе не запускался; JSON содержит16 завершённых запусков. Проба не считается полностью успешной. Перед этим были устранены инфраструктурные ошибки места AVD и отсутствия ffmpeg; они не являются результатами качества моделей.

Решение: **F32 остаётся стандартом**. F16 на данном CPU не даёт ускорения. Q8 перспективен для отдельной проверки на естественном длинном разговоре и сложных голосах; по этим пяти простым клипам менять стандартные веса нельзя. Потоковое ядро дополнительно проверяет финальный префикс и закрывает очереди при его изменении. Работающие локальные эмуляторы не затрагивались.
