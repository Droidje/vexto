## Условия и ограничения

- Обычный Android-пайплайн, APK `0.5.1-dev-1d21558`, исходники `1d21558`, явно выбран FAST. AVD Vexto_3: RAM 4096 МБ, x86_64, API 36; CPU хоста Intel Core Ultra 7 258V. Инференс локальный на CPU.
- Время взято из completion и включает фоновые эмоции; основной диалог может появиться раньше. RSS — показание встроенного watchdog, не отдельный нагрузочный тест.
- Первый запуск серии после cold boot; хост и соседние процессы не изолированы. Один запуск каждого файла не доказывает устойчивую скорость, результаты холодного/тёплого кэша смешаны.
- Публичные входы уже mono PCM16/16kHz WAV; пользовательские MP3/M4A включают декодирование. Поэтому прямое сравнение их полной скорости ограничено.
- Это демонстрационная чистая подвыборка, а не случайная оценка всего корпуса, шумных встреч или спонтанной речи. Новые результаты дополняют [предыдущие 5+5 без замены сложных случаев](synthetic-diarization-2026-11-08.md).

## Подсчёт и воспроизведение

- WER: Левенштейн по словам после нижнего регистра, ё→е и удаления пунктуации/подчёркивания; цифры не разворачиваются, слова не удаляются, атрибуция спикеров не учитывается.
- DER: точные события, UEM=[0, полная длительность), collar=0, overlap учитывается; глобальное взаимно-однозначное сопоставление меток отдельно для каждого файла. В summary сохранены отдельные DER итогового JSON и сырых DIARIZE.turns, числители/знаменатели.
- [Scoring CLI](../../tools/benchmarks/score_synthetic_fixture.py) не запускает модели: FLEURS передаётся через `--reference-text ... --wer-reference-available`; BookMix — через `--reference-rttm ... --reference-json ...`, длительность 60 с, без WER-флага.
- [Полные агрегаты и безопасная сводка 12 записей](results/clean-audio-probes-2026-11-08/summary.json). Для публичных записей рядом сохранены точные байты transcript, metadata, completion, metrics, language и processing-profile; `.gitattributes` отключает преобразование JSON-переносов. SHA256 экспортов проверяются против completion.
- Повторный инференс: импортировать сохранённый полный файл в указанный APK, явно выбрать FAST, дождаться completion, затем пересчитать все выбранные случаи. Не заменять неудобные результаты и не использовать гипотезу ASR как эталон.
