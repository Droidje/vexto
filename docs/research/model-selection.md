# Выбор моделей: исследования и решения

Какие модели выбраны для каждого этапа конвейера, почему именно они и что рассматривалось вместо них. Критерии: работа офлайн на Android с 4 ГБ RAM, русский как основной сценарий, решения по замерам на наших устройствах (не по заявлениям авторов), совместимые лицензии с notices в APK. Исходная серия проб — [модели для Android 4 ГБ](android-models-4gb.md); итоговый манифест — [engine/README](../../engine/README.md).

## Распознавание речи (основной ASR)

**Решение: GigaAM v3 E2E RNNT INT8** — русский, пунктуация и регистр из коробки, токены с временными метками.

| Кандидат | Замер на нашем AVD | Вывод |
|---|---|---|
| GigaAM v2 RNNT INT8 | 1,525 с / 433 МиБ (11,3 с аудио) | Первый рабочий кандидат, вытеснен v3 |
| Small Zipformer RU INT8 | 2,139 с / 204 МиБ | Декодирование быстрое, но инициализация съедает выигрыш |
| GigaAM v3 E2E RNNT INT8 | 1,690 с / 350 МиБ, пунктуация | **Выбран** |
| Whisper tiny/base/small | опубликованные оценки, локально не мерились | Пошёл в конвейер отдельной моделью (ниже) |
| Qwen3-ASR-0.6B, FastConformer RU, T-one, Vosk | не запускались | Остались в каталоге кандидатов |
| SenseVoice Small | русского нет в списке языков | Исключён |

E2E-вариант v3 предпочтён базовому: пунктуация и нормализация встроены. Смена декодера v3 CTC (быстрый профиль) не делает энкодер меньше — у GigaAM общий Conformer-энкодер 220M.

## Независимый второй ASR

**Решение: Whisper Large v3 Q5_0** через нативный whisper.cpp — другой класс моделей покрывает другие манеры речи, выбор на чанк делает LLM.

Что отсеяли замерами памяти: Whisper Medium ONNX INT8 (пик 2,12 ГБ — `memory_rejected`), Large с beam 5 (~2,06 ГБ — `memory_rejected`), Turbo (быстрее, но тексты отличались, эффект не изолирован). Принятая конфигурация: beam 1, best-of 1, flash-attention, контекст 512 кадров. [Прогоны](pipeline-2gb.md).

## Быстрый профиль

**Решение: GigaAM v3 E2E CTC INT8 (225 МБ) + Whisper Small Q5_1 (190 МБ)** — CTC упрощает декодирование, энкодер при этом не уменьшается; каскад уточнения возвращает тяжёлые модели только на проблемных чанках. Веса закреплены по SHA, [происхождение](fast-asr-models.md). Candidate-модели легче (Whisper Base 74M / Tiny 39M) рассматривались: без русских WER-проб и доли повторных тяжёлых проходов не подменяют текущие.

## Диаризация

**Решение: Nemotron 3, F32-линейные веса (395 МБ)** — полный end-to-end диаризатор, а не связка «сегментация + embedding + кластеризация».

DER на двух 30-секундных фрагментах AMI ([полная таблица](quick-audio-features.md)):

| Конфигурация | Train DER / Test DER | Время test |
|---|---|---|
| Nemotron 3 F32-linear | 21,47% / **14,98%** | 1,25 с |
| Nemotron 3 Q8_0 | 21,54% / — | 1,50 с |
| Sortformer 4spk-v2 Q8 | 16,35% / 15,83% | 2,55 с |
| pyannote seg + TitaNet Small | 10,37% / 21,72% | 2,78 с |
| pyannote seg + ERes2NetV2 | 12,90% / 21,72% | 19,5 с |
| pyannote seg + CAM++ | 45,52% / — | 3,35 с |

Плюсы Nemotron сверх DER: устойчивые ID голосов (на 30-минутном стрессе 344/344 якорей возвращения), до восьми спикеров, число участников не фиксируется. Точность весов выбирали отдельной пробой: F32/F16/Q8 дали DER 11,95/11,95/11,83% — F16 медленнее, Q8 не ускорил естественный фрагмент, стандарт F32 ([пробы](nemotron-precision-ci-2026-11-07.md), [продолжение](nemotron-followup-ci-2026-11-07.md)).

## Голосовые отпечатки спикеров

**Решение: ERes2Net, короткие окна с AGC, до 32 окон на человека.** На эксперименте междиалогового узнавания (AMI, 60 профилей, 15 человек) конфигурация узнала 14/14 людей с фиксированными порогами 0,80/0,08; ECAPA — 13/14, WeSpeaker — 14/14 только с длинными окнами и калибровкой. Ускоренный переход на ECAPA и калиброванные пороги не подтверждены — ERes2Net осталась. [Эксперимент](speaker-matching-quality.md).

## Локальная LLM

**Решение: Qwen3-1.7B Q4_K_M, контекст 1024, без thinking.** Роли: выбор ASR-варианта на чанк, имена спикеров из контекста, итоги и название разговора. 

Рассматривались: Qwen3-0.6B (запущена первой, но русские prompt-пробы показали проблемы thinking-шаблона; 33,5 ток/с), Qwen2.5-0.5B Q4_K_M (следующий A/B, не понадобился), Qwen3.5-0.8B (предупреждение карточки о thinking loops), Gemma 270M/1B (собственная лицензия Gemma), SmolLM2 (преимущественно английский). 1.7B взяли, когда роли LLM выросли (выбор + имена + резюме); Q4_K_M — баланс веса и качества. Все вызовы ограничены строгими инструментами: свободная генерация текста запрещена ([пробы](android-models-4gb.md)).

## Комплект и лицензии

Все 15 артефактов (3 775 095 943 байта) входят в APK и проверяются по SHA-256 при первом запуске; Android ничего не скачивает. У каждого веса закреплён источник и revision; лицензии моделей и нативных компонентов поставляются в APK ([notices](../../tools/model-notices/NOTICE.md), [лицензии нативных компонентов](../../tools/native/licenses/)). Правило серии: замены стандартных весов не обосновываются размером файлов — только замерами на нашем железе.
