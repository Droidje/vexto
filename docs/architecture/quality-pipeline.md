# Качественная расшифровка: полный конвейер

Актуализировано 8 ноября 2026 по `TranscriptionEngine`, `RecordingLanguage`, `ProcessingProfile`, `ChunkPlan` и `AcousticTurnTranscript`. Общая карта — [ARCHITECTURE](../ARCHITECTURE.md), отличие FAST — [быстрый профиль](fast-pipeline.md), ограничения — [LIMITATIONS](../LIMITATIONS.md).

## Вход и запуск

Импорт поддерживаемого Android-декодером аудио или запись микрофона → mono PCM16 WAV 16 кГц. Импорт ограничен 1 ГиБ, декодированный звук — четырьмя часами. Режим фиксируется на задание. AUTO выбирает QUALITY для длительности до пяти минут включительно.

Поставочный APK или согласованный split-комплект содержит модели заранее. Первая подготовка извлекает и проверяет SHA нужного профиля без сети; обычная разработческая сборка требует отдельной подготовки пакета. [Установка](../base-version.md#установка).

## Этапы

| Этап | Поведение QUALITY |
|---|---|
| Подготовка | Проверка пакета, декодирование, сохранение оригинала |
| GTCRN | Отдельная очищенная ASR-копия, оригинал не заменяется |
| Nemotron 3 F32 | Интервалы и локальные ID спикеров по оригиналу |
| Whisper tiny LID | Один язык по первым 30 с оригинала; может пересекаться с диаризацией по ресурсному бюджету |
| ERes2Net | Голосовые отпечатки по чистым окнам оригинала, до 32 окон на человека |
| ASR | GigaAM RNNT и/или Whisper Large по языковому маршруту |
| SDK/Qwen | Целый проверенный кандидат; имена — только при контекстных свидетельствах |
| Сборка | Полный текст по интервалам Nemotron, без саммаризации |
| Обогащение | Пунктуация, Emo, доступный детектор наложения |
| Сохранение/экспорт | Строгий JSON ТЗ и отдельные метаданные |

Перечень UI-этапов зависит от маршрута: русский не должен ждать Whisper ASR или фиктивного LLM-сравнения. Подготовка моделей может появиться повторно после LID для нужного Whisper-профиля; это не повторное выполнение всего конвейера.

### Декодирование

`AudioDecoder.decodeToWave` пишет WAV напрямую через атомарную публикацию. Готовый mono PCM16/16 кГц WAV копируется без повторного фильтра; для других частот применяется SIMD-ресэмплер (ARM64 NEON / x86_64 SSE2). Ограничение длительности проверяется по отсчётам. [Описание и замер](audio-preparation.md).

### Вход в модели

Шкала — целые отсчёты 16 кГц. В текущем quality-ядре ASR-план строит `ChunkPlan` по интервалам Nemotron: контекст 300 мс, объединение близких областей до 500 мс, чанки до 30 с с тихими границами. Пропуски записаны в `omittedRanges`; чанки и пропуски вместе покрывают исходную шкалу без дыр и дублей. Это не отдельный обязательный проход Silero VAD: Silero относится к прежнему движку/исследованиям.

### Шумоподавление

GTCRN готовит только ASR-копию. Диаризация, ERes2Net и эмоции используют оригинал.

### Диаризация

Nemotron 3 F32 сохраняет одно состояние спикеров на запись, до восьми модельных ID. Для записей длиннее пяти минут энергетическая компакция может убрать паузы от 2 с, если их сумма не меньше минуты; интервалы возвращаются в исходную шкалу. Ошибка диаризации останавливает задание с возможностью повторить его. [CLI-контракт](nemotron-cli-compatibility.md), [замер компакции](../research/diarization-compaction-avd.md).

### Язык

Обрезанный Whisper tiny (23,3 МБ) — LID, а не повторная ASR. При `detected=true, code=ru` Whisper ASR не готовится и не запускается. `be` и ошибка LID сохраняют двух-ASR маршрут (`LANGUAGE_ID_UNAVAILABLE` при ошибке); остальные определённые языки — Whisper-only. Одна метка применяется ко всему файлу. [Русский маршрут](russian-gigaam-only.md), [LID](../research/spoken-language-id.md).

### Голосовые отпечатки

ERes2Net читает до 32 окон оригинала на спикера, без повторной кластеризации. Отпечаток нужен локальному matcher для узнавания между записями. Совпавшее имя не означает совпавшего человека; ручные привязки приоритетны. [Локальная архитектура](../local-architecture.md), [качество matcher](../research/speaker-matching-quality.md).

### Две ASR и выбор

На двух-ASR маршруте GigaAM v3 E2E RNNT INT8 и Whisper Large v3 Q5_0 (beam 1, flash-attention) получают один план и одну ASR-копию. GigaAM использует до двух постоянных обработчиков; Large — один. Их допуск зависит от CPU/RAM, две Large одновременно запрещены.

Qwen3-1.7B Q4_K_M возвращает только источник кандидата, связанный SDK с `chunk_id`; ядро проверяет SHA и копирует полный оригинал. Равные тексты дают `EQUIVALENT` без LLM, отказ — явный `UNRESOLVED`. На русском GigaAM-only и остальных одно-ASR маршрутах действует `ONE_AVAILABLE`; второго RAW или факта LLM-сравнения нет. [Контракт выбора](quality-engine.md).

Имена — максимум один ограниченный запрос Qwen при найденных представлениях/обращениях. Без них LLM не вызывается; `localLlmUsed` может быть false. [Контекстные имена](context-speaker-names.md).

### Сборка

Слова выбранного целого RAW размещаются в интервалах Nemotron по наибольшему пересечению. `AcousticTurnTranscript` сохраняет `start_ms`/`end_ms` акустических интервалов, в том числе перекрытия; слово не дублируется двум спикерам. Если размещение изменяет нормализованную последовательность слов, сохраняется предыдущая сборка. Слова вне акустических интервалов остаются `speaker_unknown`. Целые миллисекунды — формат, а не гарантия точности границ до 1 мс.

### Пунктуация

Основная пунктуация приходит из ASR. Опциональный RUPunct_small INT8 меняет отдельный слой отображения («Откл / Для меня / Все спикеры»), не переписывая исходную стенограмму или строгий экспорт. Фонетические пометки сохраняются в RAW; UI/экспорт применяют документированные текстовые замены.

### Эмоции

GigaAM-Emo INT8 возвращает четыре вероятности для оценённых реплик. На совместимом драйвере возможна попытка NNAPI с CPU fallback; наличие NPU не является доказательством ускорения. QUALITY завершает эту фазу до финального завершения задания; FAST публикует основной диалог раньше. [Фоновые эмоции](background-fast-emotions.md).

### Перебивания

WavLM Base+ с обученной головой оценивает одно центральное окно 4 с на реплику длиной не меньше 4 с. Это детектор наложения, не разделение аудиоисточников. При ошибке runtime положительный ответ не выдумывается; модель может давать ложные отметки. Оценка качества — на AMI, отдельно от русского ASR. [Протокол](../research/android-overlap.md).

## Результат и артефакты

`transcript.json` содержит `transcript[]` с четырьмя полями ТЗ; `transcript.metadata.json` — имена и эмоции. `completion.json` schemaVersion 4 связывает SHA, времена, наблюдаемую память и покрытие. RAW сохраняются для реально запущенных источников. На одно-ASR маршрутах `complete` и `selectionResolved` могут быть true при `fullProfileCompleted=false`: последний флаг относится к прежнему полному двух-ASR/LLM-профилю.

Возобновление проверяет SHA аудио, профиль и результаты чанков. Экспорт открывается значком «Поделиться» → JSON / MARKDOWN / ЗВУК → «Сохранить в файл» либо системная отправка; предпросмотр не обрезает итоговый файл. [Контракты и восстановление](quality-engine.md).

## Ресурсы и память

Общий допуск — 4 CPU-потока и ограниченный native-бюджет; суммарный RSS UID контролируется с резервом 128 МиБ при бюджете 2 000 000 000 байт. Sampling не является жёстким cap. [Очереди](queued-audio-modes.md), [планировщик](adaptive-audio-core.md).

## Что здесь проверено

Поведение выше сверено с исходниками; это не новый прогон моделей. Измерения конкретных APK, исторические WER/DER и текущий русский FAST разделены в [TEST_RESULTS](../TEST_RESULTS.md). Проверки двух-ASR сборки 7 ноября не объявляются оценкой текущего русского одно-ASR пути.
