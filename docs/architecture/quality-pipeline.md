# Качественная расшифровка: полный конвейер

Для успешно определённого русского языка действует [маршрут GigaAM без Whisper](russian-gigaam-only.md).


Полное описание качественного профиля: что происходит с записью от импорта до экспорта, все этапы и все задействованные модели. Глубокие детали — в [качественном движке](quality-engine.md), [режимах и очереди](queued-audio-modes.md) и [подготовке аудио](audio-preparation.md). Как выбирается этот профиль — [выбор моделей](../research/model-selection.md); чем он отличается от быстрого — [быстрая расшифровка](fast-pipeline.md).

## Вход и запуск

- Импорт: меню «+» → «Прикрепить файл» (wav, m4a/aac, mp3, ogg/opus, flac, amr, до 1 ГиБ) или запись «Записать сейчас» / «Звонок». Повторная обработка — «Расшифровать ещё раз» / «Расшифровать на устройстве» на сведениях записи.
- Профиль задаётся в настройках «Авто / Быстрый / Качественный»; снимок выбора фиксируется при старте задания. Качественный профиль — полный: две ASR-модели, шумоподавление, фон, эмоции.
- Весов в приложении нет до первой расшифровки: полный комплект из 15 файлов (3 775 095 943 байта) входит в APK, при первом запуске извлекается выбранный профиль, каждый файл проверяется по SHA-256. Сеть не нужна.

## Этапы

Экран обработки показывает эти этапы с процентами (`Stage` в `Transcription.kt`); обработка продолжается свёрнутой и при выключенном экране.

| Этап (UI) | Что делает |
|---|---|
| Готовлю модели | Извлечение и SHA-256-проверка весов профиля |
| Декодирую аудио | Любой формат → канонический mono PCM16 16 кГц WAV |
| Убираю шум | GTCRN готовит отдельную очищенную копию для ASR |
| Разделяю голоса | Nemotron 3 F32: интервалы говорящих по всей записи |
| Определяю язык | Обрезанный Whisper tiny: первые 30 с, параллельно с диаризацией |
| Сохраняю голоса | ERes2Net: голосовые отпечатки участников для узнавания между разговорами |
| Распознаю речь | GigaAM v3 E2E RNNT INT8 по чанкам плана |
| Распознаю Whisper | Whisper Large v3 Q5_0 по тем же чанкам |
| Сравниваю варианты | Qwen3-1.7B выбирает целый ASR-вариант на чанк |
| Собираю расшифровку | Слова + интервалы → реплики с таймкодами |
| Расставляю знаки | Пунктуация выбранного ASR; опциональный слой RUPunct |
| Определяю эмоции реплик | GigaAM-Emo: четыре вероятности на реплику |
| Проверка перебиваний | Детектор одновременной речи на репликах |

### Декодирование

`AudioDecoder.decodeToWave` пишет канонический WAV напрямую (`decoded.wav.pending` → атомарная публикация `original.wav`): локальный mono PCM16/16 кГц копируется побайтно, остальные форматы идут через MediaExtractor/MediaCodec, для несовпадающих частот — SIMD-ресемплер (ARM64 NEON / x86_64 SSE2). Лимит — 4 часа декодированного аудио, контроль по отсчётам. [Замер и детали](audio-preparation.md).

### Вход в модели

Один канонический WAV — единая шкала в целых отсчётах 16 кГц; чанки плана покрывают её без пропусков и дублей (`omittedRanges`). Silero VAD отделяет речь: порог 0,5, речь от 0,2 с, для распознавания тишина от 0,3 с с полем 0,1 с; кусок длиннее 20 с режется в самом тихом кадре. План фрагментов строится по тихим границам, чанк — до 30 с; Whisper внутри видит окна до 10 с (контекст 512 кадров).

### Шумоподавление

GTCRN (потоковая нейросеть, ~48 тыс. параметров) обрабатывает отдельную ASR-копию: диаризация, голосовые отпечатки и эмоции всегда читают оригинал, поэтому фильтр не может сместить границы говорящих. Совпадение числа отсчётов проверяется аудитом (`DenoiseAudit`); оригинал и denoised-копия сохраняются.

### Диаризация

Nemotron 3 (F32-линейные веса, 395 МБ) — полный end-to-end диаризатор: интервалы всех говорящих, до восьми человек, число участников не фиксируется. Запись длиннее пяти минут перед моделью сжимается по энергии: паузы от 2 с вырезаются, если их суммарно больше минуты; шкала времени сохраняется, интервалы не склеиваются. Падение диаризации останавливает задание с возможностью повтора, а не выдаёт расшифровку со всеми `speaker_unknown` ([совместимость CLI](nemotron-cli-compatibility.md)).

### Язык

Обрезанный Whisper tiny (23,3 МБ, 99 языков; модель обучена командой из Whisper tiny) читает первые 30 секунд в процессе приложения, пока диаризация считается в отдельном worker. `ru` и `be` идут полной цепочкой; другой язык — распознавание только Whisper (`-l <код>`) без сравнения ASR. Если определитель не ответил, запись остаётся на русской цепочке с предупреждением `LANGUAGE_ID_UNAVAILABLE`. [Исследование](../research/spoken-language-id.md).

### Голосовые отпечатки

ERes2Net читает короткие окна прямо из `original.wav` (без отдельной полной PCM-копии): до 32 чистых окон на человека, равномерно по его появлению, без наложений. Отпечатки связывают людей между разговорами — и в качественном, и в быстром режиме. [Мэтчинг и его проверки](../research/speaker-matching-quality.md).

### Две ASR и выбор

- **GigaAM v3 E2E RNNT INT8** — русский текст с пунктуацией, токены с временными метками. До двух обработчиков × 2 потока.
- **Whisper Large v3 Q5_0** — независимая альтернатива (beam 1, best-of 1, flash-attention, 4 потока). Для успешно определённого русского языка Whisper пропускается — действует [маршрут одной ASR](russian-gigaam-only.md), белорусский и остальные языки используют его как прежде.
- **Qwen3-1.7B Q4_K_M** выбирает один из двух целых неизменяемых кандидатов на чанк. Модель не переписывает текст: строгий локальный инструмент принимает только ответ `"gigaam"` или `"whisper"` с заранее связанным `chunk_id`, ядро проверяет SHA скопированного кандидата. Одинаковые тексты дают проверяемый `EQUIVALENT` без вызова LLM; отказ или непоместившийся prompt — явный `UNRESOLVED`, а не незаметная подмена. Приоритета у ASR нет, порядок чередуется. Оба RAW сохраняются всегда.
- В той же сессии Qwen — максимум один дополнительный запрос (10 с): имена спикеров по представлениям и обращениям в диалоге, имя берётся из реплики, а не генерируется. [Детали](context-speaker-names.md).

### Сборка

Каждое слово получает говорящего с наибольшим пересечением его токенов с интервалами Nemotron; соседние слова одного спикера с паузой до 1 с склеиваются в реплику (подгонка границ до 1 с к границам речи). `start_ms`/`end_ms` — до миллисекунды. Интервалы с наложением не схлопываются; вне акустических интервалов — unknown, без выдуманного предыдущего голоса. Фонетические пометки ASR хранятся как есть, на экране и в экспорте заменяются на обычную запись (ə→э, ɯ→м, вдох, «пеньк пеньк»).

### Пунктуация

Знаки расставляют сами ASR-модели — итог сохраняет пунктуацию выбранного варианта. Дополнительно в настройках («Корректор») включается RUPunct_small INT8: «Откл», «Для меня», «Все спикеры». Пунктуация и регистр применяются отдельным слоем отображения: исходный текст, экспорт и работа Qwen не меняются.

### Эмоции

GigaAM-Emo (INT8) оценивает каждую реплику окнами до 8 с с весами по длительности: четыре вероятности (нейтральная, радость, грусть, злость), лицо на аватаре — наиболее вероятная. На Qualcomm/MediaTek граф пробуется на NNAPI (NPU) с автоматическим fallback на CPU при несовместимости. [NNAPI-детали](quality-engine.md).

### Перебивания

Детектор одновременной речи — замороженный WavLM Base+ и обученная командой линейная голова (3 073 параметра): одно центральное окно 4 с на реплику длиной не меньше 4 с, порог зафиксирован до теста. Короткие «угу»-подтверждения — отрицательный класс: перебиваниями не считаются. На реплике с обнаруженным наложением появляется красный значок на аватаре-эмоции, тап открывает пояснение. Ошибка детектора не влияет на текст и не создаёт ложных отметок. [Эксперимент и точность](../research/android-overlap.md).

## Результат и артефакты

- `transcript.json` — строгий контракт ТЗ: ровно `speaker_id`, `start_ms`, `end_ms`, `text`.
- `transcript.metadata.json` — внутренние данные: вероятности эмоций, имена спикеров.
- `completion.json` — SHA обоих выходов, времена стадий, память, счётчики; `original.wav`, `denoised.wav`, `chunks.json`, RAW обеих ASR и аудиты выбора сохраняются.
- Задача возобновляется после закрытия приложения: чекпоинт привязан к SHA аудио и манифесту моделей, распознавание и выбор продолжаются по фрагментам, эмоции — по репликам.
- Экспорт: «Экспортировать JSON» (контракт ТЗ), «Экспортировать MD» (имена и все вероятности эмоций), «Экспортировать звук» (без перекодирования).

## Ресурсы и память

Каждая тяжёлая модель работает в свежем процессе `:inference` и выгружается после своего этапа; модели не пересекаются, кроме лёгких параллельных стадий (язык + диаризация). Бюджет — 2 000 000 000 байт на дерево процессов приложения с резервом 128 МиБ, наблюдаемый watchdog-контроль RSS. Замеры полных прогонов — [уточнение конвейера](../research/audio-pipeline-refinement.md): 21–30 с аудио обрабатываются за 78–91 с при пике около 1,8 ГБ. Сводка актуальных результатов — [TEST_RESULTS](../TEST_RESULTS.md).

## Что здесь проверено

Сквозные офлайн-прогоны APK (включая авиарежим), сохранность обоих RAW, побайтное копирование выбранного кандидата, строгий JSON и метаданные подтверждены прогонами 7 ноября ([детали](../research/audio-pipeline-refinement.md)). Диагностический WER/DER на размеченном 30-секундном фрагменте — там же; корпусная оценка на длинных разговорах — направление дальнейших проверок ([ограничения](../LIMITATIONS.md)).
