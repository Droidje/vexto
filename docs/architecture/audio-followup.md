# Доработки после PR37

PR37 влит в dev7ноября2026, merge f676983. Эта ветка завершает отложенные части; результаты измерений добавляются по факту.

## Native-контракт Qwen

Найдена несовместимость: SDK передавал4потока, а native frontend разрешал2. Рабочая конфигурация возвращена к2; новый frontend разрешает согласованные пары2/2или4/4. Автоматическое расширение числа потоков не вводится без native-пробы.

Байтовый транспортный предел для ASR-сравнения увеличен с864до8192байт. Сам контекст остаётся1024токена, KV-кешF16 и число выходных токенов16 не увеличиваются. Реальный tokenizer проверяет полностью оформленный prompt до выделения входных токенов и до evaluation. Входы, которые не помещаются, получают явный отказ; ни текст кандидатов, ни хранимые оригиналы не обрезаются.

Отказ до evaluation не закрывает тёплый native-worker. Он обслуживает следующие чанки; остальные runtime-ошибки по-прежнему закрывают сессию. Перед SELECT приложение читает версию --help: старый кешированный бинарник получает прежний лимит864, а не несовместимый расширенный prompt. Предел для короткого определения имён остаётся864байта, с прежним бюджетом времени.

Явная повторная попытка не возвращает старый finished-снимок с неподтверждённым выбором, неудачной стадией или прежней версией селектора. Проверенные ASR-кандидаты переиспользуются; UNRESOLVED и неудачное определение имён повторяются. Успешные решения сохраняются. Автоматического бесконечного цикла повторов нет. Ранее завершённые записи не запускаются заново сами.

## Лишнее извлечение и исследовательские пробы

Whisper-only уточнение извлекает только Whisper. ГигаAM RNNT распаковывается только для русского/белорусского маршрута. Полный офлайн-пакет APK сохраняется.

В потоковой обработке первым допускается Whisper: его авторегрессионная ветка обычно дороже CTC. Иначе быстрый GigaAM мог занять оставшийся CPU/RAM-слот и простаивать в ожидании новых чанков, удерживая Whisper за барьером до конца диаризации. Модели и исходные данные не меняются.

[Ограниченное сравнение Nemotron завершено](../research/nemotron-followup-ci-2026-11-07.md): на36с естественного интервью F32/4потока13.000с, Q8/4потока13.996с, F32/2потока24.191с. Префиксы совпали с финальным RTTM. F32 остаётся стандартом. Короткие пробы меньших Whisper и сквозной Android-прогон с фактической памятью выполняются отдельно. Изменения стандартных весов не обосновываются одним размером файлов или синтетическим примером.
