# Русская запись: GigaAM без Whisper ASR

По просьбе пользователя русский язык после успешного LID проходит через одну ASR: GigaAM v3 CTC INT8 в FAST/AUTO→FAST, RNNT INT8 в QUALITY. Nemotron задаёт спикеров и временную шкалу; ERes2Net, эмоции и прочие аннотации сохраняются. QUALITY сохраняет GTCRN, FAST — без шумодава и с эмоциями после публикации диалога.

`RecordingLanguage.usesWhisper` выключен только при `detected=true, code=ru`. При ошибке LID русский fallback остаётся двойным; белорусский сохраняет обе ASR, остальные языки — Whisper-only. Tiny ONNX для определения языка остаётся: это отдельный LID, не повторное распознавание всей записи.

До LID готовится профиль без Whisper. Для маршрутов, которым он нужен, соответствующая модель готовится после LID. На русском Whisper не разворачивается, не проверяется по SHA и не запускается ни в streaming-, ни в финальной очереди. Все модели остаются внутри офлайн-APK для остальных языков, сетевых загрузок при запуске нет.

Выбор SDK копирует и проверяет целый GigaAM RAW с `ONE_AVAILABLE` и причиной `language_route_gigaam_only`. Никакого фиктивного сравнения LLM нет. И старые Whisper/refined-артефакты возобновляемого русского задания не могут попасть в итог. Qwen остаётся для одного ограниченного запроса об именах при наличии контекстных свидетельств; без них запрос пропускается. Поэтому `localLlmUsed` может быть false. Это эксперимент ускорения, а не доказательство выполнения обязательного требования кейса об участии LLM на каждой записи.

`complete` и `selectionResolved` отражают покрытие всех чанков одной ASR. Ожидаемые стадии исключают WHISPER; `fullProfileCompleted` по-прежнему описывает полный прежний двух-ASR/LLM профиль и на таком маршруте false. Этот флаг не мешает показать, сохранить и экспортировать готовый текст. Завершённые старые задания автоматически не пересчитываются.

## Проверка скорости

Контрольный файл на ноутбуке называется `Video Project 17.m4a` (346,048 с). До удаления Whisper полный FAST с Small AVX2, без тяжёлого уточнения: 476,066 с, Whisper worker 133,250 с, SELECT 197,264 с, Emo 49,255 с, пик RSS 1 783 226 368 байт. Это одиночный прогон на отдельном Pixel 7 x86_64 с 4 ГБ/4 CPU, при работающих соседних AVD. Его этапы перекрываются, их времена нельзя складывать как последовательные. Длинная запись выполнена по явному запросу пользователя.

Результат GigaAM-only будет добавлен после слияния и повторного Android-прогона. Русский WER этой записи неизвестен: эталон не предоставлен. Удаление второй ASR означает потерю альтернативного варианта для исправления ошибок GigaAM.
