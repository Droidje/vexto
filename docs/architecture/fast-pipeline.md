# Быстрая расшифровка: полный конвейер

Актуализировано 8 ноября 2026. Общие контракты — [качественный конвейер](quality-pipeline.md); профиль меняет стоимость стадий, а язык — состав ASR. [Карта архитектуры](../ARCHITECTURE.md).

## Когда включается

Настройка «Авто / Быстрый / Качественный». AUTO выбирает FAST строго при длительности больше 300 000 мс по декодированным отсчётам. Ровно пять минут — QUALITY. Выбор сохраняется на всё задание и восстановление.

## Отличия от качественного профиля

| Стадия | QUALITY | FAST |
|---|---|---|
| ASR-вход | GTCRN-копия | Оригинал, GTCRN отключён |
| Диаризация | Nemotron 3 F32 | Тот же Nemotron |
| GigaAM, когда нужен по языку | v3 E2E RNNT INT8 | v3 E2E CTC INT8 |
| Whisper ASR, когда нужен по языку | Large v3 Q5_0 | Small Q5_1 |
| Модельный контекст | На жизнь обработчика | На жизнь обработчика |
| Голосовые отпечатки | ERes2Net, обязательно | ERes2Net, обязательно |
| Эмоции | До финального завершения | После публикации основного диалога |
| Автоматический тяжёлый повтор | Не применим | Отключён |

## Общая часть конвейера

Канонический WAV, LID по первым 30 с, Nemotron, план чанков до 30 с, ERes2Net, строгая сборка и локальное хранение одинаковы по контрактам. ASR-план строится по интервалам Nemotron с контекстом и `omittedRanges`, а не отдельным обязательным Silero-проходом. Длинные паузы перед Nemotron могут компактироваться с обратным отображением шкалы. [Подробности](queued-audio-modes.md).

Языковые ветки:

- успешный `ru` → только GigaAM CTC, SDK `ONE_AVAILABLE`;
- `be` либо ошибка LID → GigaAM CTC + Whisper Small, Qwen выбирает целый кандидат;
- другой определённый язык → только Whisper Small, без сравнения двух ASR.

Равные кандидаты обходят LLM. Qwen для имён вызывается только при контекстных свидетельствах; наличие Qwen в APK не означает её вызов в каждом задании. [Русский маршрут](russian-gigaam-only.md).

## Один лёгкий проход

FAST/AUTO→FAST не запускают автоматический RNNT/Large после расхождений. `refinement-plan.json` пустой; старые refined-кандидаты не подмешиваются в выбор. Сохраняются полные RAW только реально запущенных ASR. Одинаковые PCM-чанки не означают одинаковые границы итоговых реплик: их задаёт Nemotron.

Whisper Small, когда нужен, использует один постоянный обработчик с 4 CPU-потоками, beam 1 и без temperature fallback. GigaAM FAST — один постоянный обработчик с 2 потоками; поле `gigaWorkers=2` в профиле не означает две CTC-модели: `QueuedAsrStages` ограничивает лёгкий путь одним обработчиком. Уменьшение стоимости не гарантирует качество сложного шумного фрагмента. [Происхождение весов](../research/fast-asr-models.md).

## Параллелизм

Планировщик допускает стадии в `:inference0..3` по общему CPU/RAM-бюджету. LID может пересекаться с Nemotron; на длинном новом FAST Nemotron публикует проверяемый стабильный префикс, по которому созревает ASR-очередь. Русская очередь содержит только GigaAM. Whisper Small ждёт полного CPU-ресурса; Large и Qwen допускаются эксклюзивно. Модель не загружается на каждый чанк. [Ресурсные контракты](adaptive-audio-core.md).

## Эмоции в фоне

После выбора текста и контекстных имён сохраняется `dialogue-ready.json`, диалог доступен для чтения, воспроизведения и экспорта. Внизу показывается «эмоции обрабатываются». Затем GigaAM-Emo дополняет метаданные без смены текста, спикеров и времени. Отмена/ошибка не удаляет готовую стенограмму. Следующая запись ждёт окончания фоновой фазы текущей. [Восстановление и проверки принадлежности](background-fast-emotions.md).

## Восстановление и совместимость

`completion.json` schemaVersion 4 отражает покрытие фактического маршрута. Голосовые отпечатки обязательны и в FAST. SHA-проверенные decode/диаризация/RAW переиспользуются, недостающие чанки повторяются. Завершённые старые задания автоматически не пересчитываются.

## Замеры

Текущий русский GigaAM-only на Vexto_3: 346,048 с аудио → 132,374 с вместе с Emo, основной диалог примерно через 84,4 с, наблюдаемый RSS 1 341 997 056 байт; WER/DER этого файла неизвестны. Старый двух-ASR FAST с искусственной длинной паузой: 305 с → 102 с на другом ARM64 AVD; это исторический замер другой конфигурации.
