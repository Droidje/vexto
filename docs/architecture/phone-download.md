# Полный APK: GitHub Packages → MGG → телефон

Постоянный адрес установщика: `https://distribute.droidje.com/vexto/download/vexto-offline.apk`. APK хранится одним RAW OCI-слоем в `ghcr.io/droidje/vexto-offline`. Обработчик на MGG передаёт байты потоком, без постоянной копии APK на сервере.

## Публикация

После успешного `Android CI/CD` для push в `main` запускается `phone-apk.yml`. Проверяются репозиторий, событие, ветка, успешный результат и SHA исходного запуска. Workflow берёт точный исходный commit, подписанный комплект моделей и проверенный базовый APK; собирает один полный APK и проверяет его модели, native runtime и ZIP. ORAS закреплён версией и контрольной суммой.

Проверка модели перебиваний читает manifest из APK и сверяет версию, параметры, encoder/head и лицензию с закреплёнными исходниками; размер и SHA256 проверяются по содержимому APK. Упаковочному runner не требуется повторно экспортировать модель. Если локальный manifest после экспорта присутствует, дополнительно проверяется его полное совпадение с APK.

`publish_phone_oci.py` потоково вычисляет SHA256 и размер APK, публикует неизменяемый тег `sha-<source-commit>`, проверяет OCI manifest и только затем меняет `latest`. В provenance указаны source commit, CI run ID, SHA256 и размер файла. Старый source-тег не перезаписывается другими байтами. Перед изменением `latest` повторно проверяется актуальный `main`. При ошибке предыдущий `latest` остаётся доступен. Запуски публикации сериализованы с `queue: max`, без отмены ожидающих выпусков.

Для первоначального переноса уже готового установщика есть ручной `installer_run`. Он принимает только успешный запуск прежнего phone workflow из того же репозитория и `main` или тега `vX.Y.Z`. Текущий lightweight/annotated tag разрешается через API и обязан указывать ровно на source SHA запуска. Source должен быть предком текущего `main`; исходники приложения, моделей, native и упаковки обязаны оставаться идентичными. RAW APK из Actions скачивается напрямую через artifact API и проверяется по digest/размеру. `gh run download` для `archive: false` использовать нельзя: APK сам является ZIP, и CLI извлекает его содержимое.

Первый перенос использует успешный installer run `42368229252`, source `8fbd5e16025af224237142910526b5da9714bde8`, а не локальную debug-сборку. Изменения CI и обработчика перенесены в `main` отдельно от изменений приложения в `dev`.

## Доступ и сервер

Для анонимного скачивания пакет GHCR должен быть публичным. Публичный репозиторий сам по себе не делает пакет публичным. Организация также должна разрешать публичные контейнерные пакеты; настройка находится в Organization settings → Packages. Разрешение этой политики не меняет видимость остальных существующих пакетов. Серверу при публичном пакете не нужен PAT или `GITHUB_TOKEN`.

Сервис разворачивается из [ops/apk-download-gateway](../../ops/apk-download-gateway/README.md), слушает только loopback порта 18768 и подключается точным nginx location внутри существующего HTTPS vhost `distribute.droidje.com`. Остальные маршруты домена не меняются. Перед reload обязательна проверка `nginx -t` и резервная копия изменяемого файла.

Проверяются тип OCI-артефакта, единственный слой APK, provenance, размер и SHA descriptor. Поддержаны GET, HEAD, Range/If-Range, SHA-based ETag и имя `vexto-offline.apk`. Ограничения: 4 загрузки, 8 соединений, буфер 256 КБ, контейнер 128 МБ, read-only filesystem. Кеш метаданных — 30 секунд. Буферизация и файловый кеш nginx отключены. Недоступный или неверный upstream даёт 503; базовый APK вместо полного не подставляется.

Приёмка: публичные HEAD/206/докачка, размер и MIME, полное скачивание с SHA256, совпадающим с OCI descriptor. Подробные команды находятся в инструкции gateway. Тесты публикации входят в `tools/benchmarks/tests`, тесты обработчика подключены отдельной командой в основной CI job `checks`.

Начатый поток остался привязан к прежнему blob и завершился с правильным прежним хешем; новые запросы получили новый descriptor. Устаревший If-Range корректно дал 200 нового файла вместо смешивания версий. Контейнер использовал около 19 МБ RAM при лимите 128 МБ. На телефоне установка через эту ссылку отдельно не проверялась.
