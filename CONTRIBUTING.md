# Как помочь Vexto

Открывайте [GitHub Issues](https://github.com/Droidje/vexto/issues) для ошибок, проблем с установкой и предложений. Для ошибки укажите версию Vexto и Android, модель устройства, шаги, ожидаемый и фактический результат. Для предложения опишите сценарий и какую проблему оно решает. Используйте тестовое аудио, на публикацию которого у вас есть разрешение.

Об уязвимостях сообщайте приватно по [политике безопасности](SECURITY.md).

1. Прочитайте [быстрый старт](README.md#быстрый-старт) и [правила репозитория](AGENTS.md).
2. Подготовьте изменения от актуальной `dev`. Для отдельных задач откройте PR в `dev`.
3. Запустите [проверки](README.md#проверки). Если меняется пользовательский сценарий, проверьте его в приложении и опишите устройство, версию Android и результат.
4. Сделайте небольшие коммиты по смыслу и обновите документацию вместе с поведением. Для изменений моделей укажите источник, лицензию, SHA-256 и условия проверки.

Коммиты и отчёты должны содержать только нужные для задачи файлы. Для секретов используйте локальную конфигурацию или GitHub Actions Secrets. Области ревью описаны в [CODEOWNERS](.github/CODEOWNERS).
